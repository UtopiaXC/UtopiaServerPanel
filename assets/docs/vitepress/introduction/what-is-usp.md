# Utopia Server Panel
一个轻量级的支持多种加载器和我的世界游戏版本的服务器管理面板MOD。

## 开发初衷
大概在2021年左右，我和朋友们开了一个ATM3E的公益服，但是由于我们都需要上班，因此并不能保证24小时都在游戏里，而且当年的主流1.12.2的大型mod整合启动速度实在是太慢，因此通过游戏内OP和命令行管理起来实在是太困难了。  

在当时，我就在MCMOD上提出过希望构建一个能在网页上进行快速管理的Mod：[MCMOD帖子](https://bbs.mcmod.cn/forum.php?mod=viewthread&tid=4591)，但是受到技术能力与精力所限，当时的模组止步在了构想之中。  

然而，凭借着AI神力，我终于能很荣幸地在2026年向大家介绍这个全新的服务器管理模组：Utopia Server Panel，USP。

## 功能
本面板致力于在网页中提供完整的我的世界游戏管理功能，目前，您可以通过网页进行控制台命令输入、性能分析、查看小地图、模组与服务器配置等操作，在未来，我希望联动如AE等Mod，运行玩家可以直接在网页中完成部分游戏内操作。  

- 用户管理体系与精细鉴权与玩家绑定系统
- 综合看板与性能分析与性能记录
- 网页控制台
- 网页小地图
- 模组与服务器配置编辑
- 服务器玩家主页
- 游戏内互通消息系统
- 其他系统与安全设置等
