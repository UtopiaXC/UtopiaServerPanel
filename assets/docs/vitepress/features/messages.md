# 信息与互通

信息与互通模块集成了网页端站内信、玩家离线邮件以及网页聊天室与 Minecraft 游戏内聊天的双向同步功能，已登录的面板用户即可使用。


## 站内信与离线邮件

面板为每位用户提供独立的收件箱与已发送信箱，用于接收系统通知与玩家间私信。

### 消息类型与通知

- **私信与游戏内邮件**：支持发送标题与正文内容；网页端发送标记为 `private`，游戏内通过指令发送标记为 `ingame_mail`。
- **白名单业务通知**：当有新玩家提交白名单申请时，管理员收件箱会收到 `whitelist_submitted` 通知；当申请被审核通过或拒绝时，已登录的申请人账号会收到 `whitelist_review` 通知。
- **实时状态与快捷操作**：收件箱支持按消息类型筛选、单条标记已读、一键全部已读以及直接回复发件人，新消息到达时会通过 WebSocket 实时更新未读计数。

### 跨端投递与游戏内指令

在网页端撰写站内信时，收件人既可以填写面板用户名，也可以直接填写已绑定的 Minecraft 玩家名：

1. 若目标玩家当前在线，系统在保存站内信的同时会立即向该玩家的游戏内聊天栏推送消息通知。
2. 若目标玩家离线，消息会保存在数据库中等待对方上线或登录网页端查看。
3. 玩家在游戏内可执行 `/usp msg <目标玩家或面板账号> <内容>` 向其他玩家或面板用户发送离线邮件。
4. 玩家在游戏内可执行 `/usp inbox` 查看最多 8 条未读站内信，查看后这些消息会自动标记为已投递。

## 游戏内聊天互通

聊天互通功能打通了网页聊天室与 Minecraft 服务端公屏聊天，并负责聊天历史的持久化审计。

- **游戏内消息同步至网页**：开启同步后，玩家在游戏内发送的公屏聊天会实时持久化写入数据库，并通过 WebSocket 广播到网页端公共聊天室。
- **网页端向游戏内发言**：已绑定至少一个 Minecraft 角色的面板用户，可以在网页端选择要使用的绑定角色发送公屏消息。单条消息长度上限为 `256` 个字符，发送后会同步广播到游戏内公屏，并在网页端带有 `WEB` 来源标签。
- **私聊频道审计**：聊天记录支持按 `public` 公屏频道与 `whisper` 私聊频道查询。为保障隐私，普通用户仅可查看自己参与的私聊记录，具备 `admin:1` 权限的管理员可查看全局记录。

## 联动设置

信息与互通功能的开关与保留周期在 **系统设置 -> 游戏内联动设置 -> 聊天与站内信** 中配置，详见 [游戏内联动设置](/settings/ingame)：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `chatSyncEnabled` | `true` | 是否开启游戏内聊天记录同步与网页实时推送 |
| `webChatSendEnabled` | `true` | 是否允许已绑定角色的网页用户在公共聊天室向游戏内发送消息 |
| `chatRetentionDays` | `30` | 聊天记录与站内信保留天数，范围 `1` 至 `3650` |
