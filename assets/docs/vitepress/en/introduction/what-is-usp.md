# Utopia Server Panel
A lightweight server management panel mod supporting multiple mod loaders and Minecraft versions.

## Motivation
Around 2021, my friends and I ran a free ATM3E community server. Since we all had day jobs, none of us could stay in-game 24/7, and large 1.12.2 modpacks back then took forever to launch, making it painful to manage the server through in-game OP commands or a raw console.

At that time, I posted an idea on MCMOD hoping to build a mod for quick web-based server management: [MCMOD Thread](https://bbs.mcmod.cn/forum.php?mod=viewthread&tid=4591). Limited by time and technical constraints, it never moved past the concept stage.

Thanks to the power of AI, I am finally proud to introduce this brand-new server management mod in 2026: Utopia Server Panel, USP.

## Features
This panel is dedicated to providing complete Minecraft server management features directly in the browser. Currently, you can run console commands, profile server performance, browse the web minimap, and edit mod and server configurations online. In the future, I hope to integrate with mods such as Applied Energistics so players can perform selected in-game operations directly from the web panel.

- User management, fine-grained access control, and player binding
- Comprehensive dashboard, performance profiling, and historical monitoring records
- Web console
- Web minimap
- Mod and server configuration editor
- Server player homepage
- Bidirectional in-game chat and in-site messaging system
- System and security settings
